# Generalizable Fatigue Detection from Wearable Physiological Signals

**I Charles — Final-Year Computer Science Thesis**

Does a fatigue model still work on people it has never seen?

A reproducible pipeline for detecting mental fatigue from FatigueSet (12 participants, Muse S EEG core), comparing a 1D-CNN on raw EEG windows against a classical band-power baseline — evaluated within-subject, leave-one-session-out, and leave-one-subject-out (LOSO), with strict leakage discipline.

See `PLAN.md` for the full plan and `docs/label_rules.md` for the locked label definitions.
